# AIDDLC Standard

**The open specification for AI-Driven Development Lifecycle.**

AIDDLC defines how teams should structure software development when AI participates in the development process itself. It answers the question every AI tooling vendor has avoided: not which tools to use, but how to work.

It is tooling-agnostic. It works with any AI model, any IDE, any cloud. Its value is in the structure and the principles — two organisations using completely different AI stacks should produce recognisably AIDDLC-compliant processes.

## Stability commitment

> v1.x normative requirements will not break until v3.0 at earliest.
> Patch and minor updates are backwards-compatible by definition.

AIDDLC follows **MAJOR.MINOR.PATCH** versioning. A breaking change requires a 90-day public review. See [Section 11 — Governance](AIDDLC-Standard-v1.0.md#11-governance) for the full policy.
